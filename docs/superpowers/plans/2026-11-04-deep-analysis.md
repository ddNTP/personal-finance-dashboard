## 约束

- 按人优先。付款渠道作为人的附属维度，银行与支付平台不重复汇总。
- 金额以分为整数计算；账单毛流入、性质分类、退款调整可以对账。
- 代发款项不直接等同工资；赎回本金不算收益；未知资金性质明示待确认。
- 公开数据不含原始标识、电话或完整银行卡号，不改原始账单。
- 复用原站点与 Git 远端，用户已授权执行与推送，无需再次询问。

## 审查重点

1. 多次部分退款与订单号复用不可误删。
2. 资金调拨/理财赎回/待确认转账不可当新增收入。
3. 同期比较不拿不完整年度对全年；零分母返回不可比。
4. 来源/人员/日期变更，所有视图与导出同步；不泄漏手机号、卡号或原始行。
5. 空集、银行单来源、长名称、负消费退款月份可展示且图表不溢出。
