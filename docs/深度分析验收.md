## 行为与交互验收

- Python 24 项测试通过，包含本地真实账单集成用例；JavaScript 11 项测试通过。
- 合成数据涵盖同单多次退款、最新状态快照、精确订单优先、累计退款限额、资金性质、未支付订单、无基数比较、当期/基期覆盖、CSV 数字和公式转义。
- `scripts/verify_data.py` 对计数、人民币分金额、来源隔离、银行净额和公开字段检查通过。
- Chrome 1440px 桌面与实际 390px 手机模拟验收，页面无横向溢出、无控制台错误。
- 人员切换及本人可用渠道、日期快捷选择/自定义范围、季度趋势、图例开关、对象搜索、分页、下钻对账均已实际操作。
- 非法日期显示错误；2010 年空范围显示空状态；2026 全年超出记录范围时不输出同比百分比。
- 通过页面按钮生成 CSV，读取实际下载内容验证罗勇净额 191281 与页面一致。
- PDF 导出使用浏览器打印功能，未声称独立服务器 PDF 生成服务。

## 独立审查

按 requesting-code-review 工作流委派只读独立审查。四项发现已修复并各自回归：

1. 同付款状态更新误当两笔，100 元付款退款 20 元后应为 80 元。
2. 精确退款订单应优先于相同商品描述，100+100-20 应为 180 元。
3. 当前期间也必须有覆盖，不能不完整年度与全年比较。
4. CSV 负金额须保留数值，公式前缀只处理字符串。

审查结束未报告仍未修复的 P0/P1。新公开聚合未检出长号码或邮箱。尚未跨渠道逐笔对账、未确认往来用途、不能推算完整家庭资产等边界已在页面与 README 显示。
